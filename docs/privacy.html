Polityka prywatności gcalsync

Obowiązuje od 23 września 2026 r.

Jakie dane z Google są używane

gcalsync korzysta z Google Calendar API wyłącznie w zakresie calendar.app.created. Oznacza to dostęp tylko do kalendarza utworzonego przez gcalsync („Plan WAT”) i wydarzeń w nim. Aplikacja nie ma dostępu do innych kalendarzy, wydarzeń, kontaktów, poczty ani innych danych konta Google.

Do czego są używane

Wyłącznie do tworzenia, aktualizowania i usuwania wydarzeń planu zajęć w tym kalendarzu, tak aby odpowiadał aktualnemu planowi z e-Dziekanatu.

Przechowywanie i udostępnianie

  • Token dostępu Google jest przechowywany jako zaszyfrowany sekret repozytorium GitHub (GitHub Actions) i na komputerze autora. Nie jest publikowany.
  • Dziennik zmian z każdego uruchomienia jest przechowywany jako prywatny artefakt GitHub Actions przez 7 dni, a potem usuwany automatycznie.
  • Dane nie są sprzedawane, udostępniane stronom trzecim, używane do reklam ani do trenowania modeli.

Google API Services User Data Policy

Wykorzystanie i przekazywanie informacji otrzymanych z interfejsów API Google przez gcalsync jest zgodne z Google API Services User Data Policy, w tym z wymaganiami Limited Use.

Cofnięcie dostępu

Dostęp można w każdej chwili cofnąć na stronie myaccount.google.com/permissions. Usunięcie kalendarza „Plan WAT” usuwa wszystkie dane zapisane przez gcalsync.

English summary

gcalsync uses the Google Calendar API only with the calendar.app.created scope, so it can access nothing but the calendar it created. It uses that access solely to keep the author's university timetable up to date. The OAuth token is stored as an encrypted GitHub Actions secret. Run logs are kept privately for 7 days. No data is sold, shared with third parties, used for advertising or used to train models. gcalsync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
